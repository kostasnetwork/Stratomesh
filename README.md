## pi-zero-adsb-tracker


A lightweight, low-power ADS-B flight tracker built using a Raspberry Pi Zero WH and an RTL-SDR receiver. This station tracks real-time aircraft data (1090 MHz) over Greece and visualizes it on a local map.

---

## 🛠️ Hardware Setup

Here is the exact hardware bill of materials (BOM) used for this build:

*   **SBC:** Raspberry Pi Zero WH (Pre-soldered headers)
*   **SDR Receiver:** RTL-SDR USB Dongle (RTL2832U + R860 tuner)
*   **Storage:** GoodRAM M1AA 32GB microSD (U1 Class 10)
*   **Adapter:** Cablexpert Micro USB to USB-A OTG splitter
*   **Flashing:** Esperanza USB 2.0 Card Reader
